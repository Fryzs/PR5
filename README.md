# PR5 — перевантаження операторів (C++)

Практична робота на C++: консольна програма, що демонструє перевантаження операторів `+` і `-` для дробів і масивів дробів.

## Що вміє

Через текстове меню можна:

1. додати два випадкові дроби;
2. відняти два дроби;
3. додати два масиви дробів (поелементно);
4. відняти два масиви дробів.

Клас `Operator_overload` описує дріб (чисельник/знаменник), клас `Array` — масив дробів.

## Запуск

Відкрийте `PR5.sln` у Visual Studio (з компонентом «Розробка класичних застосунків на C++») і натисніть Ctrl+F5.
